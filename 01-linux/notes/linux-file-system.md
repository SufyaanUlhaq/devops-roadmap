# Linux File System

## Key Concepts
- Linux File System contains a hierarchical structure of directories within the
root of the Operating System. The root begins with `/` and links to many directories
built on directories. The root directory is the top level directory in the Linux File System.

## commands
`ls ~/../../`
`cd /`

## Examples
`cd /` - access the root directory
`/usr` - Unified System Resources directory
`/bin` - Command binaries e.g. `cd` `mv` `rm` are stored in here for Linux terminal commands
`/boot` - Contains files related to the booting process including the Linux Kernel
`/dev` - holds device files representing devices attached to the system e.g. disks and terminals
`/etc` - contain system wide configuration files & shell scripts used to boot the 
File System

## What I Learned
The Linux File System is the root of the Operating System where all main directories
are stored - which link to other directories which contain critical data such as:
command binaries for the terminal to search when running a command, the home directory
linked to the user of the device to access applications and files saved on the system etc.
