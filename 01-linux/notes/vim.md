# Vim

## Key Concepts
- VIM is a text editor built into the terminal/shell

## Commands
`vim`

## Examples
`vim hello.txt`
`/word` - search for a word with / in the command mode
`syntax on` - turn syntax highlighting on in command mode
`n` - next occurrence `n` in command mode when searching a word with `/`
`N` - previous occurrence `N` in command mode when searching a word with `/`
`u` - to undo in vim
`CTRL+R` - to redo from doing undo

## What I Learned
Vim being a text editor with commands improving efficency when coding
