# Directories

## Key Concepts
- Create a directory that has spaces inside it, creating a structure of directories.

## Commands & Examples
`mkdir "My Project"`
`mkdir My\ Project` - Creates a directory with spacing using `\`
`mkdir My\ Project\ 2`
`mkdir -p Safari/Big\ Cats/Crocodiles` - Creates a structure of directories at once
`ls -R Safari` - outputs the directory structure to the terminal

## What I Learned
Creating directories with spaces, simultaneously and outputting the contents of each
directory within a directory structure enhances usability and accessibility in DevOps.
Using the `-R` option for `ls` recursively outputs each directory and files within the directory structure of the directory target.
