# Grep, echo, cat on files

## Key Concepts
- Creation and edits of files

## Commands && Examples
`echo "Hello World" > hello-world.txt` - use echo to print a string into a file
                                        using the direct `>` operator
`cat hello-world.txt` - use the cat command to read the contents of a file
`grep "hello" hello-world.txt` - use the grep command to search for a word in a file
`grep -r "files"` - search a directory using the -r option for contents

## What I Learned
There are various commands to input contents into files, read them without opening,
and to search for specific contents within files and directories via the Terminal.
